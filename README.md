# Breakframe

A responsive device preview tool. Enter a URL and see how your website looks on desktop, laptop, tablet, and mobile all at once.

## Setup

npm install npm run dev


## Usage

1. Enter your website URL
2. Click "Load preview"
3. Hover over devices to highlight, click to focus on one
4. Click "View all devices" to go back

## Tech

- Vue 3 + TypeScript
- Vite
- CSS Grid & Flexbox

## Devices

- Desktop: 1600 × 992
- Laptop: 1280 × 802
- Tablet: 750 × 1080
- Mobile: 320 × 480
